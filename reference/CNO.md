# Categorias de las 4 dimensiones del Clasificador Nacional de Ocupaciones 2001.

Categorias de las 4 dimensiones del Clasificador Nacional de Ocupaciones
2001.

## Uso

``` r
CNO
```

## Formato

Un data frame con 63 filas y 4 variables

- digit:

  digito para identificar la dimension del CNO

- value:

  valor que toma cada categoria dentro de una dimension

- label:

  nombre de la categoria propia a una dimension

- variable:

  nombre de la dimension del CNO
